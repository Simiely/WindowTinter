暗幕 WindowTinter v{{VERSION}} 使用说明
==================================

运行要求
--------
- Windows 10 / 11，x64
- .NET 6 Desktop Runtime (x64)
- 解压到可写目录再运行（不要放在 Program Files 或只读盘，否则配置无法保存）

快速开始
--------
1. 双击 WindowTinter.exe。
2. 点「添加窗口」，移动鼠标高亮目标窗口，左键确认；Esc / 右键取消。
3. 在底部「全局默认」调整压暗强度与圆角；需要逐窗口不同值时，展开卡片单独设置。
4. 关闭主窗口 = 收进托盘，效果继续；托盘图标双击恢复主窗口。

开机自启
--------
- 在设置里勾选「开机自启」，会写入 HKCU\Software\Microsoft\Windows\CurrentVersion\Run，命令带 /startup。
- 开机时静默启动：只显示托盘图标，不显示主窗口、不占任务栏按钮；压暗效果照常生效。
- 双击托盘图标，或在程序已运行时再次双击 exe，都会打开主窗口。
- 手动双击 exe（不带参数）仍然正常显示主窗口。

命令行参数
----------
/startup
    静默启动，仅驻留托盘。兼容 /silent、/minimized、/background、/tray。

配置
----
- 配置保存在 exe 同目录的 WindowTinter.settings.json。
- 升级只需替换 exe，配置会保留；降级到旧版本可能丢失新字段，升级前建议备份配置。

版本号
------
- 版本号唯一来源是程序集版本；窗口标题、标题栏、关于页、托盘提示都会自动显示，无需手工修改。

常见问题
--------
- Windows 提示已阻止此应用：发布包未签名，点「更多信息 → 仍要运行」。
- 调整某个窗口没反应：目标以管理员身份运行时，本程序也要「以管理员身份运行」。
- 桌面（图标层）和任务栏不支持压暗。
- 关闭主窗口后程序还在：默认「最小化到托盘」，托盘右键可退出，也可在设置里关闭该选项。

# 已知限制与不支持项

> 对应版本 7.2.0。分三类：**代码里明确不支持**、**受 Windows 机制限制**、**尚未验证**。不要把「未验证」当成「支持」。

## 1. 明确不支持 / 未实现

| 项 | 现状 | 依据 |
|---|---|---|
| 桌面（图标层）压暗 | 拾取器显式排除 `Progman` / `WorkerW`；没有其它压暗桌面的入口 | `Views/WindowPickerWindow.xaml.cs` 的目标过滤 |
| 任务栏压暗 | 拾取器排除 `Shell_TrayWnd` / `Shell_SecondaryTrayWnd` | 同上 |
| 开机自启静默启动 | 自启项写入 `"exe" /startup`，但 WPF 版**没有解析 `/startup`**，开机与手动启动一样会显示主窗口 | `App.xaml.cs` 无命令行解析；`Settings.ApplyStartWithWindows()` 只负责写注册表 |
| 第二个实例唤起第一个 | 单实例 Mutex 冲突时直接 `Shutdown()`，不激活已有窗口 | `App.OnStartup` |
| 全局热键 | 没有 `RegisterHotKey`；快捷键只在主窗口有焦点时生效 | `Views/MainWindow.xaml.cs` 的 `PreviewKeyDown` |
| 圆角快捷键同步到卡片/对话框 | 快捷键只改主窗轮廓（`Corner*`）；卡片、空态、关于/设置对话框固定 `CornerRadius=23` | XAML 中硬编码 23 |
| 自动更新 / 安装器 | 无。升级靠替换 exe | — |

## 2. 受 Windows 机制限制

- **跨完整性级别**：目标以管理员身份运行、而本程序不是时，`SetLayeredWindowAttributes` 等调用会静默失败。程序会探测并弹窗提示「以管理员身份运行」，但不会自动提权。
- **独占全屏 / D3D 独占模式**：分层窗口与 DWM 合成在全屏独占应用上通常不可见（**未验证**）。
- **目标自身是分层窗口**：程序会记录并还原其原始 alpha，不会强行移除 `WS_EX_LAYERED`；但目标若自行改写 alpha，效果可能被覆盖。
- **自绘 / 硬件合成窗口**：部分应用不响应 `SetLayeredWindowAttributes`，压暗无效（未逐一验证）。
- **Win10 无窗口圆角**：Win10 的窗口本身是直角，底板圆角会露出四角底色，建议把「圆角半径」设为 0。
- **受保护进程 / UWP**：快照 `PrintWindow` 可能失败，卡片显示占位；压暗是否生效未验证。
- **最小化动画期间**：靠 250ms 抑制窗口 + 500ms 轮询兜底，极端情况下仍可能有一帧闪烁（未做逐帧验证）。

## 3. 尚未验证（明确标注）

- **125% / 150% / 200% 缩放下的圆角缝隙**：设备像素半径用 `ceil(R * DpiScaleX)`，理论取整最多多 0.5px；外轮廓与描边弧之间本就有 9 DIP 的设计间隙，理论上不会形成 1px 缝，但**本机只有 96 DPI，未实测**。
- **混合 DPI 多屏**：manifest 声明 `PerMonitorV2`，底板吞 `WM_DPICHANGED`；跨不同缩放率显示器拖动的实际表现**未实测**。
- **有目标 / 多目标运行时的 CPU 与内存**：只测过空闲无目标（见 `PERFORMANCE.md`）。
- **长时间驻留的内存增长**：未做 24h+ soak 测试。
- **高对比度主题、屏幕阅读器、键盘全流程无障碍**：未验证。
- **ARM64 / .NET 8 运行时**：只声明与测试 x64 + .NET 6 Desktop Runtime。
- **非中文系统语言**：界面为中文硬编码，未做本地化。
- **Windows 10 与 Windows 11 的差异**：主要在 Win10 最大化钳制与圆角硬边上做过处理，Win10 全量回归未做。

## 4. 配置与部署相关

- exe 放在**只读目录**（如 `Program Files`、只读共享盘）时，`Settings.Save()` 静默失败 → 设置不持久化；不弹错误。
- 便携盘拔出后配置丢失属于预期（配置不在用户目录）。
- 升级不删除旧 `settings.json`；新版本会自动迁移旧格式。**降级到旧版本**可能导致新字段被忽略或丢失（旧版序列化只写自己的字段），升级前建议备份配置。
- 未做数字签名，SmartScreen 会拦截首次运行。
